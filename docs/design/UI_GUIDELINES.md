# UI guidelines
## Hình ảnh thương hiệu
Tên tạm Coding Academy. Sáng, dễ đọc, thân thiện học sinh, tránh rối. Màu đề xuất: primary #2563EB, nền #F8FAFC, chữ #0F172A; kiểm tra contrast thực tế, không chỉ dựa màu. Đích tiếp cận dự kiến: WCAG 2.2 mức AA (W3C, 2023) — D13.
## Điều hướng
Header: Lộ trình, Khóa học, Bài tập; tài khoản bên phải. Chưa có nội dung luyện thi/tài liệu độc lập thì không đặt link chết. Khi login có Học tiếp.
## Trang chủ
Giá trị → chọn Scratch/Python → lộ trình → khóa nổi bật → cách học. Không có rating, số học viên hoặc testimonial bịa.
## Trang học
Desktop: mục lục trái, nội dung giữa; mobile: drawer. Bài có mục tiêu, giải thích, ví dụ, thực hành và bước tiếp. Video tùy chọn, không để khung rỗng.
## Bài tập
Đề → ví dụ → gợi ý theo mức → mở lời giải sau xác nhận. Code monospace và cuộn riêng. Scratch dùng hình khối lệnh có alt text.
## Components
Button, input, select, card, dialog, badge, alert; dùng nhất quán. Form có validation server, label, focus, aria khi cần; mọi thao tác dùng bàn phím.
## Responsive/feedback
Kiểm tra tối thiểu 375px, 768px, 1280px. Loading, empty, error có hành động khôi phục. Phân biệt draft/published bằng chữ ngoài màu. Không dùng lorem ipsum trong bản nghiệm thu.
